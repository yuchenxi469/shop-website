# 雪峰优选 · SnowPeak Store

一个**前后端一体的演示购物网站**——有商品浏览、搜索、购物车、下单、物流追踪、AI 客服、星空完成页等完整电商体验流程。后端用 Python 标准库手写，**不需要安装任何第三方包**，跑起来就能演示。
## 项目介绍
本项目是一个模拟购物平台：涵盖登录注册页面 用户打开浏览器就能进行逛商城、搜索商品、加入购物车、填收货地址下单，然后看到物流信息一步步推进，以及最后的订单情况——背后是真正的后端接口在提供数据、计算价格、生成物流轨迹。

**这个项目做的事**：
- 把"电商网站核心流程"完整展现（浏览 → 搜索 → 加购 → 登录之后下单 → 物流追踪 → 完成页）
- 后端有真实的 HTTP 接口（API），数据存在 JSON 文件里，重启不掉线
- 前端是一个单页应用（SPA），页面切换不刷新
- 内置一个规则驱动的AI客服助手，能回答商品推荐和预算相关问题，提供个性化的购物服务
## 技术栈
| 层面 | 用的技术 | 通俗解释 |
|---|---|---|
| **前端 - 结构** | HTML5 | 网页骨架，定义"页面上有什么东西" |
| **前端 - 样式** | CSS3 + CSS 变量 + Flex/Grid | 视觉外观和响应式布局（手机/平板/电脑自动适配） |
| **前端 - 逻辑** | 原生 JavaScript（ES6+） | 交互行为，没用 React/Vue 等框架，纯手写 |
| **后端 - 语言** | Python 3 标准库 | 只用 Python 自带的模块，零第三方依赖 |
| **后端 - HTTP 服务** | `http.server.ThreadingHTTPServer` | Python内置的轻量 HTTP 服务器（多线程，能同时响应多个请求） |
| **数据存储** | JSON 文件（data/*.json） | 用 .json 文件当简易"数据库"——读写方便、不需要装 MySQL 等数据库软件 |
| **认证方式** | Bearer Token（令牌） | 登录后后端发一个"通行证"给浏览器，之后每次请求都带上它证明身份 |
| **密码安全** | PBKDF2-HMAC-SHA256 + 盐（salt） | 密码不存明文，而是用不可逆的哈希算法+随机盐存储，防泄露 |
| **并发保护** | `threading.RLock`（可重入锁） | 多人同时操作数据文件时，保证不会写乱、数据打架 |
| **XSS 防护** | 前端 HTML 转义 `esc()` + 后端校验 | 防止恶意用户在输入框里注入脚本代码攻击别人 |

```bash

> ```

## 后端 API 一览
所有接口路径以 `/api/` 开头，返回 JSON 格式数据（`{ "ok": true/false, ... }`）。
| 方法 | 路径 | 作用 | 需要登录？ |
|---|---|---|---|
| POST | `/api/register` | 注册新用户 | ❌ |
| POST | `/api/login` | 登录拿 Token | ❌ |
| POST | `/api/logout` | 退出登录 | ✅ |
| GET | `/api/me` | 查看当前登录用户 | ✅ |
| PATCH | `/api/profile` | 修改性别/城市 | ✅ |
| GET | `/api/products` | 商品列表（支持 `?q=&category=&min=&max=&sort=&page=` 查询参数） | ❌ |
| GET | `/api/products/<id>` | 商品详情 | ❌ |
| POST | `/api/orders` | 下单（服务端计价+生成物流轨迹） | ✅ |
| GET | `/api/orders` | 我的订单列表 | ✅ |
| GET | `/api/orders/<id>` | 订单详情（含轨迹时间线） | ✅ |
| POST | `/api/orders/<id>/advance` | 物流推进一步（模拟发货→运输→派送…） | ✅ |
| POST | `/api/orders/<id>/cancel` | 取消订单（仅待发货可取消） | ✅ |
| GET | `/api/addresses` | 地址簿列表 | ✅ |
| POST | `/api/addresses` | 新增收货地址 | ✅ |
| PUT | `/api/addresses/<id>` | 修改地址 | ✅ |
| DELETE | `/api/addresses/<id>` | 删除地址 | ✅ |
> "需要登录"意味着请求头必须带上 `Authorization: Bearer <token>`，否则返回 401。
## 设计理念（适合进阶阅读）
- **前后端分离但不依赖框架**：前端只负责展示和交互，所有数据由后端 API 提供；但没用 Flask/Django/React 等框架——用纯标准库实现，更适合学习“底层发生了什么”。
- **服务端计价**：价格和优惠计算在后端完成（前端传的商品 ID → 后端查表算金额），不信任前端传的金额，防篡改。
- **幂等下单（clientOrderId）**：同一个下单请求发两次只创建一笔订单，防止用户连点导致重复下单。
- **确定性伪随机（物流轨迹）**：用订单号 MD5 做种子（seed）生成轨迹——同一笔订单刷新多少次轨迹内容不变，看起来像真的物流信息。
- **会话落盘**：Token 存 JSON 文件而非内存，重启服务器用户不用重新登录。
- **防御式存储**：JSON 文件读写包了通用函数 + RLock，文件缺失返回默认值，不会因为“没有数据文件”就崩溃。

## 关键函数一览
下面列出项目里比较核心的函数，解释它们分别做什么：
| 函数 | 所在文件 | 作用 |
|---|---|---|

| `build_traces(order)` | server.py | 根据订单信息生成 6 段物流轨迹（揽收→发往→中转→派送→送达→签收），时间递增且确定不重复 |

| `mulberry32(seed)` | app.js | 确定性伪随机数生成器，用商品 ID 做种子生成卖点/评价等内容，刷新不变 |
| `openDetail(id)` | app.js | 打开商品详情弹窗，同时重置规格选择和数量 |

## 安全与存储决策
这里解释几个“为什么这样做”和“为什么没那样做”的关键决策：
### 密码存储
- **做法**：用户注册时后端用 `hash_password()` 生成盐(salt) + PBKDF2-SHA256 哈希，只把盐值和哈希结果存入 users.json，**原始密码不以任何形式落盘**。
- **为什么不存明文**：万一数据文件被读到，明文密码直接泄露；而单向哈希不可逆，配合 60 万次迭代的 PBKDF2 算法，暴力破解成本极高。
- **盐的作用**：每个用户随机盐，保证即使两人密码相同，存储的哈希值也不同，防止彩虹表攻击。
### 为什么没用 ORM
- **ORM（对象关系映射）**是连接代码和关系数据库的抽象层（如 SQLAlchemy、Django ORM）。本项目用的是 JSON 文件存储，没有关系型数据库，所以 ORM 没有用武之地。
- 实际访问方式很简单：`load_json_file(path, default)` 读文件，`save_json_file(path, obj)` 写文件，每个接口函数直接操作列表/字典。
- 如果未来要迁移到 SQLite（Python 标准库自带 `sqlite3`）或 MySQL，那时引入 ORM 才有意义。
### XSS（跨站脚本攻击）防护
- **前端**：所有用户输入（收货人、地址、物流文本等）在插入 HTML 前必须经过 `esc()` 转义，即使攻击者在输入框里写 `<script>alert(1)</script>` 也只会显示为文本。
- **后端**：参数校验拒绝非法字符（如昵称正则 `^[\w\u4e00-\u9fa5]{2,16}$`），数据文件 HTTP 访问已封 404。

### 登录防爆破
- 同一昵称连续失败 5 次后自动锁定 10 分钟，返回 `429 Too Many Requests`，服务端内存记录，重启清零。同时错误文案统一为“昵称或密码错误”，不暴露用户是否存在。

## 页面样式与设计
### 配色体系
用 CSS 变量定义主题色，所有样式统一引用，改一处全站生效：
| 变量 | 值 | 用途 |
|---|---|---|
| `--brand` | `#1f6feb` (蓝) | 主色调：按钮、激活态、品牌强调 |
| `--brand-deep` | `#14407e` (深蓝) | 渐变深色端、标题 |
| `--accent` | `#d4a017` (金) | 评分星、标签、“热销”标记 |
| `--price` | `#e4393c` (红) | 价格、角标数字 |
| `--bg` | `#f5f7fa` (浅灰) | 页面底色，商品卡白色形成对比 |
| `--radius` | `14px` | 统一圆角（卡片、按钮、弹窗） |

### 布局结构
- **顶部吸顶导航**：`position: sticky` + `backdrop-filter: blur(10px)` 磨砂效果，下滚时始终可见
- **底部固定 Tab Bar**：4 个导航按钮（首页/客服/购物车/我的）固定屏幕底部，`backdrop-filter: blur` 半透明磨砂
- **商品网格**：CSS Grid 自适应列数（`repeat(auto-fill, minmax(240px, 1fr))`），大屏多列小屏自动收窄
- **购物车双模式**：整页卡片(`.cart-page-card`) + 侧边抽屉(`.cart-drawer`)，抽屉用 `transform: translateX(105%) → none` 实现滑入动画
- **商品详情弹窗**：居中遮罩 + 卡片式弹窗（左侧大图 + 右侧规格/数量/操作），关闭点击遮罩任意位置

### 星空完成页
- 背景：线性渐变压暗 + 星空实拍图(`starry.jpg`) `cover` 填充
- 卡片：**毛玻璃效果**（`backdrop-filter: blur(10px)` + 半透明深蓝底色），浮在星空上有层次感
- 星点动画：JS 生成 36 个随机位置的 `<i>` 元素，用 CSS `@keyframes twinkle` 做透明度+缩放循环动画，模拟星空闪烁
- 徽章动画：绿色✓弹出（`@keyframes donePop` 从 scale(0) → scale(1.2) → scale(1)`）
### 响应式策略
| 断点 | 调整 |
|---|---|
| `≤ 900px` | 商品网格缩小为 2~3 列，详情弹窗图片区域压缩 |
| `≤ 560px` | 单列布局、完成页 meta 信息竖排、底部 Tab Bar 字小 |
| `@media (hover: none)` | 收藏按钮常显（触屏无 hover 状态） |
### 微交互细节
- 加购物车时角标弹跳动画（`bump()` 函数调用 `el.animate` scale 1→1.5→1）
- Toast 提示从底部滑入，2.5s 自动消失
- 商品卡图片 hover 微放大（`transform: scale(1.03)` + `transition .5s`）
- 抽屉滑出使用 `cubic-bezier(.22, 1, .36, 1)` 弹性曲线，手感自然
